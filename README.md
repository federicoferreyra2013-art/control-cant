# Control-CANT — versión nueva

Sistema web estático para GitHub Pages.

## Roles
- Administrador: acceso total y corrección/eliminación.
- Pañolero: combustible, viajes/producción, órdenes y máquinas.
- Comandero: viajes/producción y planta.
- Veedor 1 y Veedor 2: consulta.
- Maquinistas: partes de máquinas y órdenes.
- Mecánicos: órdenes de trabajo y máquinas.
- Camioneros: consulta de viajes; NO cargan viajes.

## Importante
Esta versión funciona como prototipo en el navegador y guarda datos en localStorage. GitHub Pages no proporciona por sí solo una base de datos ni usuarios reales compartidos. Para producción real, habrá que conectar un backend/base de datos.
